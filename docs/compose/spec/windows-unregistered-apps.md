# Windows 未登记应用发现与移除

Windows 应用列表不应只依赖 ARP（控制面板的卸载登记）。源码安装、解压运行、用户目录内的自更新应用也需要显示，但发现一个程序并不代表拥有它的父目录，更不代表能猜出卸载命令。

## 数据与分层

`core/apps.rs` 的 `AppDiscovery` 保存可执行文件、实际指向它的快捷方式，以及可选的 `OfficialUninstaller`。平台负责发现和执行，core 提供能力判定，UI 根据能力显示官方卸载或移除文件。未登记应用使用独立 ID，不参加基于父目录的版本合并。

## 发现来源

- 枚举真实登录用户的桌面（含重定向桌面）、开始菜单，以及公共桌面和开始菜单；只读取本地 `.lnk`，不调用 ShellLink Resolve。
- 扫描深度最多 4 层，每个根最多 4000 个条目，支持扫描取消，不跟随目录链接。
- 普通快捷方式必须指向存在的本地 `.exe`；适配器有精确安装证据时接受已丢失的启动器以恢复半卸载。UNC、系统保护路径、系统根目录内的直接目标、目录伪装的 exe 均排除。
- 适配器可补充已知默认安装布局，支持没有快捷方式的 CLI 安装。目前 Hermes 提供默认候选。
- 用规范路径去重；已有登记项按安装路径优先，同名的独立安装保留。GUI 和 CLI 经适配器确认属于同一安装时合并。

## 两种操作能力

| 证据 | 操作 | 默认文件范围 |
| --- | --- | --- |
| 只有可执行文件和快捷方式 | 移除程序文件与快捷方式 | 精确 exe 和仍指向该 exe 的快捷方式 |
| 内容与布局匹配官方适配器 | 官方卸载；另可查看残留 | 适配器确认的程序目录 |

普通 portable 程序的父目录可能是下载目录或共享工具目录，因此绝不从 exe 推断父目录所有权。对未登记应用，同名数据目录、注册表及无法复核目标的快捷方式均降为“可能”，默认不勾选。删除仍统一经过 core 安全闸门。

## 官方适配器契约

适配器验证内容与布局，返回程序根目录、显示信息和结构化执行参数；不能因显示名命中就授权卸载，也不能搜索到 `uninstall.*` 后直接执行。增加支持时在适配器表注册新的检测函数，并补能力、保留数据与完成判据测试。

执行前重新读取安装证据。命令绕过 shell，以实际登录用户身份执行；提权进程使用桌面用户令牌并复核 SID，无法取得该用户环境则拒绝执行。成功必须由所有安装产物消失和程序进程退出证明，连续四次确认；空 ARP 登记、退出码 0、路径读取失败均不算卸载完成。

## Hermes 首个适配器

通过 `pyproject.toml` 的 hermes-agent 包名、constants 文件、`.git` 和 GUI/CLI 布局确认源码安装。半卸载也可由精确源码规范路径散列对应的安装记录，以及限定在该状态目录内的 venv 路径确认。

使用外部 Python 的隔离模式调用 `hermes_cli.uninstall --mode lite`，显式传入源码根与 HERMES_HOME，工作目录留在数据 home 内。官方 lite 模式保留配置、会话等用户数据；解释器不在待删除源码中，避免 Windows 自删除锁。缺少外部 Python 或官方模块时，已确认源码安装可使用恢复清理；密封安装仍只有精确文件移除能力。

补充清理覆盖安装记录内的外置 venv、tools facts 中的工具包、已确认缓存安装器和引导脚本、启动器、快捷方式及 Gateway 登记。用户 PATH 和 Hermes 环境变量只移除精确指向该安装的值，任务只按执行参数中的安装路径认领。所有删除经过 core cleaner，完成后核验文件与登记。facts 和安装状态最后删除，失败后仍可重试。其他安装存在时保留共享工具；命名 profile、运行中的程序或安装器会阻止不安全删除。配置、会话、凭据、未知文件和非空数据 home 保留。

## 验证与范围

回归覆盖无 ARP、改名快捷方式、GUI/CLI 去重、同名多安装、普通 portable 精确范围、受保护/网络/缺失目标、缺少运行时、保留数据，以及退出成功却没有移除产物的情况。实机列表扫描已找到本机 Hermes；真正的命令执行在独立测试安装中验证，没有卸载本机 Hermes。

当前发现范围是本地 exe 快捷方式与已实现适配器的默认布局；不进行全盘 exe 扫描，未实现无快捷方式未知布局、任意脚本、包管理器或 UWP 的通用卸载。

## Pitfalls 核对

已完整核对本仓库现有 P1–P9：P1 的文件判据和登记卸载解析保持；P2/P3 卡片防护不受影响；P4 WMI 不变；P5 只读目录删除和 P6 ACL 补救仍由原 cleaner 执行；P7 重启删除分类不变；P8 原登记卸载的 UAC 等待不变，新官方适配器单独等待产物；P9 更新架构与 helper 不变。用户提供的额外约束也保持：保护规则统一、名称不授权删除、活库未知占用拒删、首次绘制不做同步应用扫描。

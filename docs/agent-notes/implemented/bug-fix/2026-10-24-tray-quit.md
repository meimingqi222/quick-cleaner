# Agent Note: An admitted quit closes the main window instead of hiding it

Status: implemented

## Problem

Quit from the tray menu, Quit in the tray popover and Cmd+Q did nothing
whenever the tray existed. MyGo's `App.Quit` fires `OnBeforeQuit`, then
closes every window, and abandons the whole quit if any `OnClose` prevents
it. The main window's `OnClose` always prevented a close and hid the window
while a tray existed, so every quit stopped there. Driving the real tray menu
on Windows reproduced it: the process was still running 8s after Quit.

## Decision

`internal/app/run.go`: `onBeforeQuit` sets `Root.quitting` once it admits a
quit. `onMainClose` hides to the tray only when no quit is in progress.
Pending work (`quitBlocked`: a confirmation, a mutation, an update install)
still refuses both the quit and the close, and starts a cancellation instead.
Both handlers share `quitBlocked`.

## Alternatives considered

- Call `App.Exit` from the tray. Rejected: it skips the quit events, so
  pending-work refusal and `OnWillQuit` cleanup would no longer run, and
  Cmd+Q would still fail.
- Set the flag only in the tray handlers. Rejected: `RoleQuit` items and
  Cmd+Q call `App.Quit` directly and would stay broken.

## Consequences

Every quit path exits. The close button still hides to the tray. A quit that
`OnBeforeQuit` admits but another listener later abandons leaves `quitting`
set. The next close then exits instead of hiding, and no current listener
can trigger this.

## Verification

- `internal/app/tray_quit_test.go::TestAdmittedQuitClosesTheMainWindowInsteadOfHidingIt`
- `internal/app/tray_quit_test.go::TestQuitWithPendingWorkIsRefusedAndNotRemembered`

Proved: without the `!r.quitting` guard, the first test failed at
`the main window hid during a quit; MyGo abandons the quit`; see
`docs/agent-notes-evidence/2026-10-24-tray-quit-red.log`. With the guard
restored, it passes; see `docs/agent-notes-evidence/2026-10-24-tray-quit-green.log`.
On Windows, posting a right click to the tray callback window and choosing
Quit left the pre-fix build running. The fixed build exited with code 0. The
close button still hid the window, and the tray's show-main item and left
click still worked.
